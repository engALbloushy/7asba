# Hand Scorekeeper — web app

Score tracker for the card game Hand (هند). Works on iPhone and Android, offline, and keeps games on the phone.

## Install on iPhone
1. Open the site link in **Safari**.
2. Tap **Share** → **Add to Home Screen** → **Add**.

## Install on Android
Open the link in Chrome → menu (⋮) → **Add to Home screen** / **Install app**.

## Updating
Replace `index.html` and change `VERSION` in `sw.js` (e.g. `hand-v2`). Phones pick up the update the next time the app is opened online.
